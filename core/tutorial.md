# tutorial

Source folder: `asset/core/tutorial/`

For overall OP-CORE context, see `overview.md`.

`tutorial` defines runnable or renderable examples for learning core behavior.

This folder owns tutorial pages such as `OP.phtml`, `Config.phtml`, `Request.phtml`, `Template.phtml`, `Unit.phtml`, `Module.phtml`, `Error.phtml`, `Env.phtml`, `D.phtml`, and `Timestamp.phtml`.

Use this folder for examples that demonstrate how a core feature is used. Do not place runtime implementation, CI checks, interface contracts, or reference documentation here.

Tutorial changes should follow the feature file they explain, but tutorial pages remain examples rather than normative API definitions.
